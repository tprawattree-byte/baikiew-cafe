# ใบเขียว · Baikiew Café

เว็บไซต์ตัวอย่าง (mockup) ร้านคาเฟ่สไตล์มินิมอล โทนสีเขียว–ขาว
สร้างด้วย HTML / CSS / JavaScript ล้วน ไม่มี build step และไม่มี dependency

## สิ่งที่มีในเว็บ

| ส่วน | รายละเอียด |
|---|---|
| Header | sticky nav, scroll-spy ไฮไลต์เมนูตามตำแหน่งที่เลื่อน, hamburger บนมือถือ |
| Hero | ภาพประกอบ SVG แก้วกาแฟ + ใบไม้ (มีอนิเมชันไอน้ำ), แถบ marquee |
| เกี่ยวกับเรา | จุดขาย 4 ข้อ |
| เมนู | 6 หมวด 50+ รายการ พร้อมคำบรรยาย ราคา ร้อน/เย็น/ปั่น, ป้ายกำกับ (ซิกเนเจอร์ / ใหม่ / วีแกน / ไม่มีคาเฟอีน), ตัวกรองหมวด + ช่องค้นหาแบบเรียลไทม์ |
| ซิกเนเจอร์ | การ์ดเมนูเด่น 3 รายการ |
| บรรยากาศ | แกลเลอรี CSS art 4 ช่อง |
| รีวิว | 3 รีวิวบนพื้นเขียวเข้ม |
| ที่ตั้ง & เวลา | ที่อยู่, ตารางเวลาทำการ, ตัวบอกสถานะ "เปิด/ปิดอยู่ตอนนี้" คำนวณจากเวลาจริง |
| จองโต๊ะ | ฟอร์มพร้อม validation ฝั่ง client และข้อความยืนยัน (ไม่ส่งข้อมูลออกจริง) |
| Footer | ลิงก์, โซเชียล, ฟอร์มสมัครจดหมายข่าว |

รองรับ responsive ตั้งแต่ 320px ขึ้นไป, `prefers-reduced-motion`, skip link และ focus ring สำหรับคีย์บอร์ด

## โครงสร้างไฟล์

```
baikiew-cafe/
├── index.html        # โครงหน้าเว็บทั้งหมด
├── styles.css        # ดีไซน์ระบบ + responsive
├── menu-data.js      # ข้อมูลเมนูทั้งหมด (แก้ราคา/เพิ่มเมนูที่นี่)
├── app.js            # nav, reveal, ตัวกรองเมนู, ฟอร์ม
├── vercel.json       # ตั้งค่า static hosting
└── assets/favicon.svg
```

## รันบนเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือถ้ามี Python:

```bash
python3 -m http.server 4000
```

แล้วเปิด http://localhost:4000

## แก้ไขเมนู

แก้ไฟล์ `menu-data.js` ไฟล์เดียว — หน้าเว็บจะ render ใหม่เองทั้งหมด

```js
{
  th: 'ชื่อเมนูภาษาไทย',
  en: 'English Name',
  desc: 'คำบรรยาย',
  price: [ร้อน, เย็น, ปั่น],   // ใส่ null ถ้าไม่มีตัวเลือกนั้น
  single: 120,                  // ใช้แทน price สำหรับอาหาร/ขนม
  tags: ['signature']           // signature | new | vegan | caffeine-free
}
```

## Deploy

โปรเจกต์เป็น static site ล้วน — Vercel จะ serve ได้ทันทีโดยไม่ต้องตั้ง build command
