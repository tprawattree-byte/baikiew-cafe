# ปลาร้าเด้อ · Plara Der

> ยกครัวอีสานมาไว้กลางกรุงเทพ — อาหารอีสานต้นตำรับแท้ ๆ จากอุบลราชธานี
> น้ำปลาร้าปรุงสุก สะอาด ปลอดภัย

เว็บไซต์ร้านอาหารอีสาน สไตล์มินิมอล โทนเขียว–ขาว
สร้างด้วย HTML / CSS / JavaScript ล้วน ไม่มี build step และไม่มี dependency

## สิ่งที่มีในเว็บ

| ส่วน | รายละเอียด |
|---|---|
| Header | sticky nav, scroll-spy ไฮไลต์เมนูตามตำแหน่งที่เลื่อน, hamburger บนมือถือ |
| Hero | ภาพประกอบ SVG ครกส้มตำ + สาก (มีอนิเมชันเครื่องปรุงเด้ง), แถบ marquee |
| เกี่ยวกับเรา | จุดขาย 4 ข้อ เน้นน้ำปลาร้าปรุงสุกและวัตถุดิบจากอุบล |
| เมนู | 14 หมวด 190+ รายการ ถอดจากเล่มเมนูจริง พร้อมตัวกรองหมวดและช่องค้นหาแบบเรียลไทม์ |
| ของดีเมืองอุบล | การ์ดเมนูเด่น 3 รายการ (ตำถาดสะบัด, หม่ำเนื้อ, ตำปูปลาร้า) |
| บรรยากาศ | แกลเลอรี 4 ช่อง (รูปจริง 1 + CSS art 3) |
| รีวิว | 3 รีวิวบนพื้นเขียวเข้ม |
| บทความ | 2 บทความยาว พร้อม FAQ และ structured data |
| ที่ตั้ง & เวลา | ที่อยู่, ตารางเวลาทำการ, ตัวบอกสถานะ "เปิด/ปิดอยู่ตอนนี้" คำนวณจากเวลาจริง |
| จองโต๊ะ | ฟอร์มพร้อม validation ฝั่ง client (ไม่ส่งข้อมูลออกจริง) |

รองรับ responsive ตั้งแต่ 320px, `prefers-reduced-motion`, skip link และ focus ring สำหรับคีย์บอร์ด

## SEO

- Title / meta description / keywords เจาะคำ **อาหารอีสาน**, **อาหารอีสานต้นตำรับ**, **น้ำปลาร้าปรุงสุก**, **ส้มตำ**
- `canonical`, Open Graph และ Twitter Card ครบทุกหน้า
- JSON-LD: `Restaurant` (ที่อยู่ พิกัด เวลาเปิด เรตติ้ง) + `WebSite` บนหน้าแรก,
  `BlogPosting` + `BreadcrumbList` + `FAQPage` บนบทความทุกชิ้น
- `robots.txt` และ `sitemap.xml`
- Internal linking ระหว่างหน้าแรก ↔ หน้ารวมบทความ ↔ บทความทั้งสอง

> ⚠️ **ก่อนขึ้นโดเมนจริง** ต้องแก้ URL ในไฟล์เหล่านี้ให้เป็นโดเมนใหม่:
> `index.html`, `blog/index.html`, `blog/*.html` (canonical + og:url + JSON-LD),
> `sitemap.xml` และ `robots.txt`

## โครงสร้างไฟล์

```
.
├── index.html                      # หน้าแรก
├── styles.css                      # ดีไซน์ระบบ + responsive + สไตล์บทความ
├── menu-data.js                    # ข้อมูลเมนูทั้งหมด (แก้ราคา/เพิ่มเมนูที่นี่)
├── app.js                          # nav, reveal, ตัวกรองเมนู, เวลาเปิด-ปิด, ฟอร์ม
├── blog/
│   ├── index.html                  # หน้ารวมบทความ
│   ├── cooked-plara-safe.html      # น้ำปลาร้าปรุงสุกคืออะไร
│   └── isaan-somtam-guide.html     # ส้มตำอีสานต้นตำรับ
├── assets/
│   ├── favicon.svg
│   └── isan-restaurant.jpg
├── robots.txt
├── sitemap.xml
└── vercel.json
```

## รันบนเครื่อง

```bash
python3 -m http.server 4173
```

แล้วเปิด http://localhost:4173

> หมายเหตุ: ลิงก์บทความเป็นแบบไม่มี `.html` ซึ่งทำงานได้บน Vercel (`cleanUrls`)
> แต่บน `python3 -m http.server` ต้องเติม `.html` เอง

## แก้ไขเมนู

แก้ไฟล์ `menu-data.js` ไฟล์เดียว — หน้าเว็บจะ render ใหม่เองทั้งหมด

```js
{
  th: 'ชื่อเมนูภาษาไทย',
  en: 'English Name',
  desc: 'คำบรรยาย',        // ใส่หรือไม่ใส่ก็ได้
  single: 120,              // ราคาเดียว
  price: [ร้อน, เย็น, ปั่น], // ใช้แทน single สำหรับเครื่องดื่ม (null = ไม่มีตัวเลือกนั้น)
  tags: ['signature']       // signature | new | vegan | caffeine-free
}
```
